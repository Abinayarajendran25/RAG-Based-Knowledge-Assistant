# RAG-Based-Knowledge-Assistant
A RAG (Retrieval-Augmented Generation) Based Knowledge Assistant is an AI-powered system that answers questions using uploaded documents such as PDFs, Word files, and text files. It retrieves relevant information from a document database and generates accurate, context-aware responses, reducing hallucinations and improving answer reliability.
